01 / DIAGNOSIS

A repeatable DTC workflow

A diagnostic trouble code points to a detected condition; it is not, by itself, proof that a specific part has failed.

  1. Confirm the customer's complaint and the conditions when it occurs.
  2. Check battery condition, charging system, grounds, connectors and relevant fuses.
  3. Scan the relevant modules and save code status, freeze-frame and available live data before clearing codes.
  4. Use the exact manufacturer test plan. Change one variable at a time and record results.
  5. After repair, reproduce the original conditions, rescan and verify the fault has not returned.

02 / ECU IDENTIFICATION

Identify the controller first

Similar names do not guarantee that two files are compatible. Record the complete context before comparing or programming.

  • Vehicle make, model, year and engine variant
  • ECU maker, family and hardware number
  • Software/calibration ID and readable part numbers
  • Read method, tool version, file size and memory region

03 / WIRING

Test the circuit, not just the part

Before condemning a sensor or module, verify the circuit using the manufacturer's test procedure and correct diagram revision.

  • Inspect connector fit, corrosion and water entry.
  • Use the matching wiring diagram and pinout.
  • Measure supply, ground and signal only as specified.
  • Check loaded voltage drop where the test plan calls for it.

04 / BINARY FILES

Preserve the original file

Keep an untouched original and confirm file identity before analysis or programming. Never make an edited copy the only surviving copy.

  • Store the original as read-only and work from a separate copy.
  • Record file size and SHA-256 hash, read tool and method.
  • Label full/virtual reads and memory regions clearly.
  • Verify exact ECU compatibility and checksums with approved tooling.

05 / CUSTOMER DATA

Share only what is necessary

Vehicle files and workshop records may contain customer or vehicle identifiers. Protect them as confidential service data.

  • Remove names, phone numbers, VINs and registration details from public examples.
  • Do not post account credentials, private download links or API keys.
  • Keep original files and work records in approved private storage.
  • Share files only with authorized recipients through a verified channel.

06 / WORKSHOP SAFETY

Safety-critical systems need approved procedures

Follow manufacturer instructions for SRS/airbag, high-voltage, immobilizer and anti-theft work. Never probe live SRS circuits or bypass safety protections.

Before work: confirm the correct service manual, required isolation procedure, suitable test-equipment rating and applicable rules. Stop when the module identity or safe test procedure is uncertain.
