# Software Store image policy

- Public software listings use first-party category artwork served from ecufileservice.in.
- Do not publish third-party product-detail URLs, download URLs, source links, or publisher website links in the catalogue.
- Keep category images visually consistent: dark navy base, teal technical highlights, restrained amber accents, no third-party logos or watermarks.
- Use the software title and version as catalogue text; do not imply official affiliation or guaranteed compatibility.
- Verify the public catalogue API and dynamically generated product pages before deployment.
