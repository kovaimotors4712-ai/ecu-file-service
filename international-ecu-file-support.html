INTERNATIONAL REQUEST PROCESS

What to include in your enquiry

International requests are assessed individually. Vehicle-market differences, ECU variants, file type, tool read method, local regulations and the exact work requested can affect whether a request can be supported.

01

Vehicle details

Country or market, make, model, model year, engine, fuel type and vehicle variant.

02

Control-module details

ECU or SRS manufacturer, module family, hardware number, software or calibration ID and readable part numbers.

03

Original read and request

Original file, file size, read method and tool information, plus a clear description of the diagnostic issue or requested service.

SERVICE SCOPE

Compatibility and serviceability are confirmed first

Do not assume that a file for a similar model, engine or ECU is interchangeable. We review the exact identifiers and available information before confirming whether a request can proceed. No service, turnaround time or vehicle compatibility is guaranteed until the request has been reviewed.

Requests must relate to lawful diagnostics and repair. Safety-related systems must be repaired and verified in accordance with vehicle-manufacturer procedures and applicable local requirements. We do not recommend disabling legally required emissions or vehicle-safety systems.

COMMON QUESTIONS

International workshop enquiries

Can a workshop outside India submit a request?

Yes. International workshops can submit an enquiry. Acceptance depends on the exact vehicle and module, the information supplied, serviceability and applicable local requirements.

Does a matching vehicle model mean the file is compatible?

No. Hardware numbers, software IDs, engine variants, market specifications and read methods must be checked. Similar model names alone are not enough.

What should I send first?

Provide the vehicle and module identifiers, a description of the issue, the original unmodified file and the tool/read method. Keep an untouched backup of the original file.

Are all services available in every country?

No. Availability is not universal. Each enquiry is reviewed individually, and a request may be declined if compatibility, safety, legal or technical requirements cannot be met.
